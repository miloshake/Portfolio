## 04 // Running & Deploying This Portfolio

This repository contains a **zero-build, sleek minimal notebook-themed portfolio website** with Sky Blue accents (`index.html`, `styles.css`, `script.js`).

- **Local Preview:** Open `index.html` directly in any browser, or serve locally via `npx serve .` / VS Code Live Server.
- **GitHub Pages:** Enable GitHub Pages in repository **Settings → Pages → Deploy from branch (`main` / `/root`)**.
